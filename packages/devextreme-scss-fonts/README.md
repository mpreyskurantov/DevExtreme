# DevExtreme embedded fonts

Private workspace package containing embedded font assets for DevExtreme themes. These assets provide local font fallbacks.

`devextreme-scss` uses these assets during theme builds. The build pipeline copies `fonts/` to `devextreme/artifacts/css/fonts` and to `scss/widgets/material/typography/fonts` in the assembled distribution.
